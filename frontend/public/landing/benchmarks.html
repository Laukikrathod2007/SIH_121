Benchmark Details

Run against one real 74-page Volve daily drilling report. Every extracted value is checked against drilling-physics bounds (e.g. mud weight 7–22 ppg); OCR digit-slips like “3.2” for “13.2” are auto-repaired and logged, not silently dropped.
