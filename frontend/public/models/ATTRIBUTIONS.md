# Surface model asset notes

These GLB files are original procedural engineering-visualization geometry
generated for this project by `scripts/build_surface_wellhead.py`.

| Asset | Use | Source / creator | License | Format |
|---|---|---|---|---|
| `active_surface_rig.glb` | Detailed active-well land installation | Original project geometry; generated by NWIS visualization scripts | Project-authored; no third-party asset | GLB / glTF 2.0 |
| `offshore_surface_rig.glb` | Illustrative offshore drilling unit for compact subsurface transition view | Original project geometry; generated by NWIS visualization scripts | Project-authored; no third-party asset | GLB / glTF 2.0 |
| `selected_surface_wellhead.glb` | Medium-detail selected offset wellhead | Original project geometry; generated by NWIS visualization scripts | Project-authored; no third-party asset | GLB / glTF 2.0 |
| `offset_wellhead.glb` | Lightweight other-offset wellhead | Original project geometry; generated by NWIS visualization scripts | Project-authored; no third-party asset | GLB / glTF 2.0 |

The scene does not download or include the inspected third-party candidate
models. The candidate oil rig / drilling rig / wellhead assets were not used
because their available previews/specifications were not sufficient to verify
that their geometry, land/offshore context, and production size were suitable
for this field scene. No external creator attribution is therefore implied.

All four models are **representational surface assets**. They are not
photographs, surveyed facilities, or evidence that the depicted equipment is
installed at a particular well. Their origins are anchored to actual provider
well coordinates, and Cesium clamps the model base to the active terrain when
terrain is available. Model scale and detail are visual only; well coordinates,
distance, ranking, and subsurface data remain provider-backed.

Regenerate the files with:

```powershell
python scripts/build_surface_wellhead.py
```
